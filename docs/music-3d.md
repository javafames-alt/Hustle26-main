# Music3D

Включение: **Render → Music3D**. Модуль по умолчанию выключен и работает независимо от музыкального виджета Interface.

Music3D использует текущий трек и позицию воспроизведения из `MediaSession`, а строки — из общего сервиса `Lyrics`. Для отображения нужен найденный текст песни. При отсутствии текста надписи в мире не создаются.

Каждая новая строка получает собственную позицию перед камерой и сохраняет её при движении и поворотах игрока. Если впереди блок, строка размещается перед ним. Ориентация тоже фиксируется при появлении строки. Буквы плавно проявляются с волной, имеют слой глубины и подсвечиваются по прогрессу строки. Цвета берутся из текущей темы и обновляются сразу при её смене.

Настройки модуля:

- **Дистанция строк** — 1,5–12 блоков.
- **Размер текста** — 0,5–2×; длинная строка дополнительно уменьшается до ширины поля зрения.
- **Шлейф строк** — 0–4 секунды затухания предыдущих строк. Одновременно остаётся максимум четыре строки.
- **Свечение текста** — контур букв в цвете темы.

Пауза останавливает анимацию и подсветку. Перемотка и смена трека очищают предыдущие строки. Выключение модуля, выход из мира и смена измерения очищают размещённый текст. F1 скрывает его вместе с HUD.

Проверка логики размещения, паузы, перемотки, повторов припева, затухания и сохранения настроек: `gradlew.bat verifyMusic3D`.
